Program tiles: original vs v2

The same little board twice, no gameplay: a U-turn, a straight run with step, rotator and counter, a detector whose branches turn through corner belts, a counter check, a magic detector, rotated counter tiles and the start marker.
Original (2012): the old pre-drawn frames from images/sprytszyt.png, 50 px frames drawn at 0.9 scale on a 47 px pitch with 2 px gaps. It has no corner belts.
New v2 (current build): the frames now in the game, from images/tiles/program-tiles.png (drawn by tools/art/tiles/program-tiles.mjs): anti-aliased, 54 px frames on a 54 px pitch, no gaps.
Both use the 2012 timing: every frame lasts 25 ms (rate 0.05, halved by Quintus), rotators turn 3° per frame (60 frames per loop), belts run 20 frames per chevron, step arrows cross a tile in 60 frames. Both columns read the same clock, as the game does.
The game canvas is not Retina-aware, so on a Retina screen “Canvas: game” is what the game shows. “Canvas: sharp” renders at device pixels.
