| ui-icons | `icon_32.png` | 32×32 | Favicon. |

Constraints for any replacement art:

- The canvas is a fixed 1024×768 and tiles are drawn at 50×50. New art must keep frame sizes and frame counts, or `data/sprites.json` and the `Q.animations` table in `script.js` change with it.
- Rotation is applied at runtime (tiles have an `angle`), so instruction and terrain tiles must read correctly in all four orientations.
- Six counter colours (red, blue, green, purple, yellow, pink) must stay distinguishable, including for colour-blind players. Add a shape or glyph cue rather than relying on hue.

Suggested order: instruction tiles → robot + terrain → UI buttons → backgrounds → rewards → end-level robots → intro screens. Direction is still the user's call.
